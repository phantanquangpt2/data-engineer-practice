
# Data Engineer Practice

My personal learning repository for Data Engineering fundamentals.

I practice collecting data from REST APIs, processing data with Python, storing data in CSV and SQLite, and querying data using SQL.

## Skills & Tools

- **Python:** requests, pandas
- **Data Processing:** CSV, JSON, data cleaning
- **REST APIs:** Open-Meteo, REST Countries, CoinGecko
- **Database:** SQLite
- **SQL:** SUM, AVG, COUNT, GROUP BY, HAVING
- **Tools:** VS Code, Git, GitHub

## Projects

### 1. REST API Data Collection

- Retrieve data from public APIs.
- Parse JSON responses using Python.
- Process and export data to CSV.

### 2. Cryptocurrency Price Data

- Retrieve cryptocurrency prices from CoinGecko.
- Process API responses using Python and pandas.
- Save processed results to CSV.

### 3. SQL Practice

- Practice SQL queries using SQLite.
- Perform data aggregation with GROUP BY and HAVING.

## Learning Goals

- Strengthen Python and SQL skills.
- Build reliable ETL pipelines.
- Learn data validation and incremental data loading.
